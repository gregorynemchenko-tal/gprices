# Kabalator — 14 ноября 2026

Главный интерфейс: «Акции», «Моя корзина», «Все продукты».
Чеки, история личных продуктов и настройки убраны из навигации.
Акции и каталог фильтруются по категории и сети, поддерживают поиск.
Условия акции раскрываются отдельно. Корзина хранит количество товаров
и сравнивает полную доступную стоимость; неполные цены не определяют победителя.

Подключена Keshet Teamim через публичный HTTPS PublishedPrices, без FTPS.
Справочник — 27 филиалов. В сравнении выбран западный филиал Ришон-ле-Циона,
Лехи, 4 (024): 16 418 товаров, 6 061 записей акций на товары.
Общий опубликованный каталог: 27 312 товаров, 43 352 филиальные цены,
15 140 записей акций. Разные упаковки и внутренние коды не объединяются.

Keshet обновляется в GitHub каждые два часа. Проверочный живой прогон:
https://github.com/gregorynemchenko-tal/gprices/actions/runs/43623090600
Остальные три источника сохраняют прежние ограничения доступа из облака.

Фото проверяются заранее пакетами, восемь соединений и не более примерно
5,5 начала запросов в секунду на обработчик. Для Rami Levy используются HEAD
и прямые адреса подтверждённых изображений; копий с неустановленными правами
не создаётся. Open Food Facts CC BY-SA 3.0 хранится в собственном Storage.
Массовое первоначальное заполнение: workflow «Backfill product photos»,
две параллельные порции, отдельная итоговая публикация после всех порций.
Регулярная проверка по расписанию — 2 500 товаров за запуск, результаты
сохраняются, проверенные адреса повторно проверяются через 30 дней.
Сетевые ошибки повторяются; отсутствие доступа не выдаётся за готовое фото.
Это не гарантия фотографии для товара, у которого ни один источник её не отдаёт.

Выпуск каталога включает все подготовленные фото, без прежнего ограничения
первой тысячей записей. Товары и акции с готовыми фото показываются первыми.
Остальной полный каталог остаётся доступным через фильтры и поиск.

При обновлении из новой сети сохраняются прежние русские/ивритские
поисковые подсказки. Недостающие варианты восстановлены по предыдущему
проверенному снимку того же товара. Новая сеть не стирает названия остальных.

## Worker commands

Python 3.12. Server variables: SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY.
Never commit credentials or copy the server key into the mobile app.

```sh
python catalog_worker.py --chain keshet_teamim --max-jobs 2
python catalog_worker.py --retailer-images 2500 --images 5 --release-only
```

SQL files are already applied to simjxoshjprrexdixbso. Do not apply them blindly
to another project. verify-publication.sql rolls back all its test records.
